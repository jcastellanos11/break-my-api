# Break My API — Design Discovery Pack

A **design-only** reference package prepared from three screenshots selected by the project owner:

1. `design-references/01-cake-dashboard.png` — Cake, dashboard layout and hierarchy.
2. `design-references/02-uxcel-education.png` — Uxcel, educational catalog and cards.
3. `design-references/03-canva-visualization.png` — Canva, side controls and central visualization workspace.

Read `DESIGN_REFERENCE_ANALYSIS.md`, then `UI_REDESIGN_BRIEF.md`, and use `CODEX_DESIGN_DISCOVERY_PROMPT.md` in Codex in the **Break My API repository**.

**Private working references:** These are the user's selected screenshots of third-party products. Keep screenshots in a local design-references directory and out of the public repository. Draw on principles; do not trace/copy protected layouts, logos, illustrations, original copy, or brand identities. Add `design-references/` to `.git/info/exclude` or `.gitignore` where appropriate. Only documentation you own should be committed if desired.

**Stage scope:** design research and specification; **NO CODE CHANGES**. The app currently includes P1.5.1 modules; P1.5.2 (visual request flow) has not been implemented, and P1.6 (release QA) remains pending.
